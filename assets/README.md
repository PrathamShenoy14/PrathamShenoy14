# Assets

- `fonts/`: Space Grotesk and JetBrains Mono (SIL Open Font License 1.1, see the `OFL-*.txt` files).
  `*.subset.woff2` and `metrics.json` are generated by `scripts/tools/fonts.py`.
- `icons/`: brand icons from [Simple Icons](https://simpleicons.org/) (CC0 1.0). Add a tool by
  dropping its `<slug>.svg` here and listing it under `tools` in `profile.config.json`.

## Editing the profile

Edit `profile.config.json`, then run `node scripts/build.mjs` (Node.js 20+). Merged PRs and the
contribution calendar are fetched from GitHub automatically, and the workflow in
`.github/workflows/refresh.yml` rebuilds everything daily. Never edit `README.md` or `dist/` by hand.
